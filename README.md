# 有条

一款基于 Flutter 的轻量级待办 / 任务管理应用，支持分类、优先级、回收站、数据备份导出、深浅色主题、周趋势统计、定时提醒与专注环境音。

应用名「有条」，包名 `com.example.todolist`（发布标识，发布后不可更改）。

当前版本 **v2.3.6**（versionCode 57）　·　开源协议 **[MIT](LICENSE)**

## ✨ 功能特性

- 📝 **任务管理**：新增、编辑、删除，支持分类与优先级
- 👉 **手势操作**：向左滑编辑、向右滑删除
- 🗑️ **回收站**：误删任务可在回收站恢复或彻底删除
- 💾 **数据安全**：本地备份 / 恢复，导出 CSV 与 Markdown
- 🌗 **主题**：浅色 / 深色，支持跟随系统自动切换
- 📊 **看板（统计 + 分列）**：完成率、优先级分布、分类进度、周趋势（含上周对比）；两列看板（待办/已完成）可拖拽或点击切换状态
- 🖼️ **看板一键分享**：把看板数据生成一张约 1080px 宽的竖版长图，面板内实时预览、按需勾选板块（完成率/统计/优先级/分类/趋势/看板明细），支持浅深色卡片与「隐藏任务标题」，可保存到相册（`Pictures/有条`，免存储权限）或直接分享
- 🏠 **首页一键分享**：与看板分享同源，把首页「日期分区」清单（逾期/今天/未来/每天/已完成）生成同样的竖版长图——每个分区下直接列出任务标题、分类与相对截止时间，行首色条跟随优先级；复用相同面板与导出能力，不混入看板分析板块
- 🔔 **定时提醒**：支持任务的定时通知
- 🔁 **每日提醒**：为任务设定「每天固定时间提醒」（如每天 7:00 背单词），每天准时推送，独立于一次性截止提醒
- ✅ **多选批量删除**：长按任务进入多选模式，可一次勾选多个任务批量删除（支持撤销）
- 🛡️ **后台提醒守护**：前台服务常驻，保证在国产 ROM（ColorOS / MIUI 等）上划掉后台后定时提醒仍能准点触发；看板页提供守护状态卡
- 🔎 **首页筛选**：筛选芯片（全部/待办/已完成/逾期）与看板统计卡联动，点击统计卡直达对应筛选
- 🗓️ **首页按日期分区**：「逾期 / 今天 / 未来 / 每天」四段 + 「已完成」，按截止日期真正落段（无截止归入「未来」，每日提醒任务独占「每天」），互不重叠；空分区自动隐藏，各分区标题字号统一
- 📅 **日历（月 / 周视图 + 拖拽改期）**：日历 Tab 支持「月视图 / 周视图」分段切换；月视图按每天完成数做热力着色，当天到期任务以条状呈现；任务条支持长按拖拽到任意日期格**松手即改期**（自动重排提醒），已完成任务灰显不可拖；点日期查看当天完成明细
- 🕛 **每日任务 00:00 自动重置**：无需打开 App，每天午夜由系统闹钟后台将已完成的每日任务重置为未完成，真正实现「每天循环打卡」
- 🎨 **设计**：Material 3 设计语言
- ⏱️ **专注计时（番茄钟）**：新增「专注」Tab，内置番茄钟倒计时（25 / 5 / 15 分钟预设，可开始 / 暂停 / 停止），可关联某一任务，自动记录每次专注时长与今日专注统计，数据本地持久化
- 🌊 **专注环境音（淡入淡出 + 多音叠加）**：内置白 / 粉 / 棕噪音与雨声 / 海浪 / 篝火 / 风声七种零版权环境音（程序化合成），支持多选同时叠加播放、切换时 500ms 音量渐变避免爆音，选择自动记忆

### 关于 Gradle（本机 Windows 提示）

本工程在 Windows 上构建时，建议把 `GRADLE_USER_HOME` 设在与工程**同盘**的路径（如 `D:/workbuddy/.gradle`），可规避 Gradle 9.1 跨盘符号链接快照失败（`not a regular file`）。另外 `android/app/build.gradle.kts` 已对 `merge*NativeLibs` / `extract*NativeSymbolTables` 任务关闭状态追踪作为兜底。

## 🔔 后台提醒守护（重要）

为了让定时提醒在「划掉后台」后依然准时触发，应用内置了一个**前台守护服务**：

- 服务运行在独立进程 `:guard`，App 主进程被划掉后守护进程仍存活；
- 闹钟的接收器（`ScheduledNotificationReceiver`）也声明在 `:guard` 进程，闹钟到点直接在守护进程内投递通知，无需重启主进程；
- 设置页提供「后台提醒守护」总开关（默认开），关闭即停止该服务。

**注意事项（国产 ROM 用户必读）：**

1. 状态栏会常驻一条「有条 · 提醒守护中」通知，这是前台服务的硬性要求，点开即回到 App，无需理会。
2. **不要用手机管家的「一键加速 / 强力清理」去清「有条」** —— 那是强杀，前台服务也挡不住；正常使用「最近任务上滑划掉」不受影响。
3. 建议一并开启：设置 → 应用 → 有条 → **自启动**、**电池无限制 / 允许后台运行**、**精确闹钟（闹钟和提醒）**，并把 App 加入手机管家清理白名单、在最近任务卡片下拉锁定。
4. 开机重启后守护服务会自动重新排程已有的定时提醒。

> 为什么需要这套机制？普通本地 App 在 ColorOS / MIUI 上被划掉后台后，系统会冻结其后台闹钟，导致定时通知不响。微信 / QQ 能扛住是因为接入了厂商系统推送（ROM 默认白名单），而本地 App 没有服务器，只能用「前台服务 + 独立进程 + 同进程接收器」这套方案保活。
