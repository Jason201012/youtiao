## 三、逐项详述

### S1. 本地自动备份 —— 仍是全清单唯一「不做会后悔」

- **为什么刚需**：v2.5.9 把回收站的被动安全做完了，但主动数据安全的最后一块拼图——自动备份——仍然缺失。误卸载 / 手机丢失时，从未手动备份的用户一次性丢失全部任务、习惯打卡、专注历史。
- **实现方案**（与上版一致，微调落点）：
  1. `TaskProvider.load()` 尾部挂 `_autoBackupIfNeeded()`：比较 SP 中 `last_auto_backup_date` 与今天；
  2. 复用现有备份导出函数生成 schema v3 JSON，写 `<docs>/backup/auto/YYYY-MM-DD.json`（用 [data_io.dart](data_io.dart#L24-L34) 现成原子写）；
  3. 滚动保留最近 7 份；设置页加开关（默认开）+ 最近成功时间；恢复面板列快照一键还原。
- **验收标准**：跨日首启产生当日快照；同日不重复写；第 8 份出现清除最旧；关闭开关即停；快照走现有恢复流程还原完整。
- **工作量**：1.5~2 天。

### S2. 子任务文本纳入全局搜索

- [search_index.dart](search_index.dart#L40-L50) 的 `_matchesTask` 加一行：`t.subtasks.any((s) => s.title.toLowerCase().contains(q))`。
- 验收：搜子任务关键词命中父任务；2 个单测。≤0.5 天。

### S3. 备份导入校验

- 恢复是覆盖性操作，选错文件会「新数据没进来、旧数据先被清」。在恢复前增加 `validateBackupJson`：顶层 Map + schemaVersion ≥1 + tasks/habits/focus_sessions 至少一键类型正确 + 抽样反序列化首条 Task。四类坏样本单测（CSV 冒充 / 截断 JSON / 空 Map / 缺版本号）。~0.5 天。

### S5. 任务一键转习惯

- 编辑弹层或详情页操作栏加「转为习惯」：字段映射预览（title→title、repeatWeekdays→weekdays、repeatMinute→reminderMinute）→ `HabitProvider.addHabit` → 询问删除原任务（走回收站可撤销）。注意 v2.6.1 新增的 `startDate` 不参与映射（习惯无此概念）。~1 天。

### B1+. 周目标补全：本周完成任务数

- v2.6.1 已有「每日专注目标」，同一模式补一个「每周完成任务数目标」（SP 存一个 int）：首页本周回顾摘要卡显示「12/20」进度条，周报页对比目标 vs 实际。复用刚验证过的交互范式，成本极低。~1 天。

### A1 / A2 / A4

方案与上版一致（拼音预计算字段进任务 JSON / CustomPaint 0-23h 直方图 / local_auth + USE_BIOMETRIC 权限 + 30s 返回阈值），不再赘述。A4 注意模拟器无生物识别时的降级路径。

### ~~D0. 补齐 CHANGELOG~~（✅ 已完成）

- 官方已通过提交 `1dbd148` 倒序补录 v2.5.6→v2.6.1 六节，并严谨核实了 v2.5.5 属真实缺发、v2.5.9 debug 签名事故的交叉标注。此项关闭。
