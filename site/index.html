FEATURES

一个应用，装下完整的事务流

从记录到循环，从打卡到专注，再到统计与备份——各环节自成一体，又彼此衔接。

任务与日历

分类、优先级、标签、批量编辑与模板；月 / 周日历视图长按拖拽即可改期，支持自然语言快速录入。

循环与提醒

每天 / 每周 / 每月循环，支持农历重复；独立守护进程保提醒准点送达，通知上可直接完成、打卡或顺延。

习惯打卡

量化打卡、宽限日与周目标；专属热力图、当前 / 最长 / 累计连续统计，破纪录全屏庆祝。

番茄专注

25 / 5 番茄循环，可绑定任务；白噪音、雨声、海浪等七种零版权环境音自由叠加，专注时长自动记录。

统计与分享

看板完成率、优先级分布、周趋势与成就体系；看板和清单一键生成竖版长图，直接保存或分享。
